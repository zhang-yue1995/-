# 财务公式文档

## 文档概述
本文档详细说明鑫速录系统中所有财务指标的计算公式、业务含义、输入字段来源以及异常处理逻辑。涵盖6大类共36个财务指标的完整计算方法。

## 指标体系总览

### 六大维度分布

| 维度 | 指标数量 | 核心指标数 | 权重占比 |
|------|---------|-----------|---------|
| 短期偿债能力 | 5 | 3 | 15% |
| 长期偿债能力 | 6 | 4 | 10% |
| 盈利能力 | 7 | 5 | 25% |
| 营运效率 | 7 | 4 | 20% |
| 现金流能力 | 6 | 3 | 15% |
| 成长能力 | 5 | 3 | 15% |
| **合计** | **36** | **22** | **100%** |

### 计算精度要求

- **金额类指标**：保留2位小数（万元）
- **比率类指标**：保留4位小数
- **天数类指标**：保留1位小数（天）
- **百分比类指标**：保留2位小数（%）
- **得分类指标**：整数（0-100）

### 除零和空值处理通用规则

```java
// 伪代码：安全除法
function safeDivide(numerator, denominator, defaultValue = null) {
    if (denominator == null || denominator == 0) {
        return defaultValue;  // 返回null或预设默认值
    }
    return numerator / denominator;
}

// 空值传播规则
// 如果任一输入值为null，且该值参与运算，则结果为null
// 特例：加法中null视为0（如资产合计）
```

## 一、短期偿债能力指标（5个）

### 1.1 流动比率 (Current Ratio)

**指标编码**: `CURRENT_RATIO`
**单位**: 倍
**权重**: 0.05
**最优范围**: 1.5 - 2.5

#### 计算公式
```
流动比率 = 流动资产合计 ÷ 流动负债合计
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 | 字段编码 |
|-----|-------|--------|---------|
| 流动资产合计 | balance_sheet | totalCurrentAssets | TOTAL_CURRENT_ASSETS |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities | TOTAL_CURRENT_LIABILITIES |

#### 业务含义
衡量企业短期债务偿还能力的最重要指标。反映每1元流动负债有多少流动资产作为保障。

#### 判断标准
- **≥ 2.0**: 偿债能力强，但可能资金闲置
- **1.5 - 2.0**: 健康水平
- **1.0 - 1.5**: 需关注，流动性偏紧
- **< 1.0**: 高风险，无法覆盖短期债务

#### 示例计算
```
流动资产合计 = 25,000 万元
流动负债合计 = 30,000 万元
流动比率 = 25,000 ÷ 30,000 = 0.8333 倍 ⚠️ 偏低
```

---

### 1.2 速动比率 (Quick Ratio)

**指标编码**: `QUICK_RATIO`
**单位**: 倍
**权重**: 0.04
**最优范围**: 1.0 - 1.5

#### 计算公式
```
速动比率 = (流动资产合计 - 存货) ÷ 流动负债合计
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 流动资产合计 | balance_sheet | totalCurrentAssets |
| 存货 | balance_sheet_item | endingBalance (itemCode=INVENTORY) |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities |

#### 业务含义
剔除存货后的短期偿债能力，因为存货变现能力较弱。比流动比率更严格。

#### 判断标准
- **≥ 1.0**: 优秀
- **0.8 - 1.0**: 良好
- **0.5 - 0.8**: 一般
- **< 0.5**: 较差

---

### 1.3 保守速动比率 (Conservative Quick Ratio)

**指标编码**: `CONSERVATIVE_QUICK_RATIO`
**单位**: 倍
**权重**: 0.02
**最优范围**: 0.6 - 1.0

#### 计算公式
```
保守速动比率 = (货币资金 + 交易性金融资产 + 应收票据 + 应收账款) ÷ 流动负债合计
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 货币资金 | balance_sheet_item | CASH_AND_CASH_EQUIVALENTS |
| 交易性金融资产 | balance_sheet_item | TRADING_FINANCIAL_ASSETS |
| 应收票据 | balance_sheet_item | NOTES_RECEIVABLE |
| 应收账款 | balance_sheet_item | ACCOUNTS_RECEIVABLE |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities |

#### 业务含义
最严格的短期偿债能力指标，仅考虑变现能力最强的资产。

---

### 1.4 现金比率 (Cash Ratio)

**指标编码**: `CASH_RATIO`
**单位**: 倍
**权重**: 0.02
**最优范围**: 0.2 - 0.5

#### 计算公式
```
现金比率 = (货币资金 + 交易性金融资产) ÷ 流动负债合计
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 货币资金 | balance_sheet_item | CASH_AND_CASH_EQUIVALENTS |
| 交易性金融资产 | balance_sheet_item | TRADING_FINANCIAL_ASSETS |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities |

#### 业务含义
极端情况下（立即偿还所有流动负债），企业的现金支付能力。

---

### 1.5 营运资本 (Working Capital)

**指标编码**: `WORKING_CAPITAL`
**单位**: 万元
**权重**: 0.02
**最优范围**: > 0（正值）

#### 计算公式
```
营运资本 = 流动资产合计 - 流动负债合计
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 流动资产合计 | balance_sheet | totalCurrentAssets |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities |

#### 业务含义
企业用于日常运营的净流动资金。负值表示营运资金短缺。

---

## 二、长期偿债能力指标（6个）

### 2.1 资产负债率 (Debt-to-Asset Ratio)

**指标编码**: `DEBT_TO_ASSET_RATIO`
**单位**: %
**权重**: 0.04
**最优范围**: 40% - 60%

#### 计算公式
```
资产负债率 = (负债总额 ÷ 资产总额) × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 负债总额 | balance_sheet | totalLiabilities |
| 资产总额 | balance_sheet | totalAssets |

#### 业务含义
反映企业总资产中有多少是通过借债筹集的。衡量企业长期偿债能力和财务风险的最核心指标。

#### 判断标准
- **< 40%**: 财务保守，杠杆利用不足
- **40% - 60%**: 健康水平
- **60% - 80%**: 风险偏高
- **> 80%**: 高风险，偿债压力大

#### 示例计算
```
负债总额 = 45,000 万元
资产总额 = 50,000 万元
资产负债率 = (45,000 ÷ 50,000) × 100% = 90.00% 🔴 极高
```

---

### 2.2 产权比率 (Equity Ratio / Debt-to-Equity Ratio)

**指标编码**: `EQUITY_RATIO`
**单位**: %
**权重**: 0.03
**最优范围**: 70% - 150%

#### 计算公式
```
产权比率 = (负债总额 ÷ 所有者权益总额) × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 负债总额 | balance_sheet | totalLiabilities |
| 所有者权益总额 | balance_sheet | totalEquity |

#### 业务含义
反映债权人提供的资本与股东提供的资本的相对关系。体现企业财务结构的稳健程度。

---

### 2.3 有形净值债务率 (Tangible Net Value Debt Ratio)

**指标编码**: `TANGIBLE_NET_VALUE_DEBT_RATIO`
**单位**: %
**权重**: 0.01
**最优范围**: < 100%

#### 计算公式
```
有形净值债务率 = 负债总额 ÷ (所有者权益总额 - 无形资产 - 商誉) × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 负债总额 | balance_sheet | totalLiabilities |
| 所有者权益总额 | balance_sheet | totalEquity |
| 无形资产 | balance_sheet_item | INTANGIBLE_ASSETS |
| 商誉 | balance_sheet_item | GOODWILL |

#### 业务含义
更谨慎地评价企业偿债能力，剔除无形资产等难以变现的资产。

---

### 2.4 利息保障倍数 (Interest Coverage Ratio)

**指标编码**: `INTEREST_COVERAGE_RATIO`
**单位**: 倍
**权重**: 0.03
**最优范围**: > 3

#### 计算公式
```
利息保障倍数 = (利润总额 + 利息费用) ÷ 利息费用
           ≈ (营业利润 + 利息费用) ÷ 利息费用
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 利润总额 | income_statement | totalProfit |
| 利息费用 | income_statement_item | FINANCING_EXPENSES（需提取利息部分） |

**注意**: 若利润表中未单独列示利息费用，可用财务费用近似代替。

#### 业务含义
衡量企业支付利息的能力。倍数越高，偿债安全性越强。

#### 判断标准
- **> 5**: 安全性很高
- **3 - 5**: 安全
- **1.5 - 3**: 有一定风险
- **< 1.5**: 危险，可能无法支付利息

---

### 2.5 长期负债比率 (Long-term Debt Ratio)

**指标编码**: `LONG_TERM_DEBT_RATIO`
**单位**: %
**权重**: 0.02
**最优范围**: < 30%

#### 计算公式
```
长期负债比率 = 非流动负债合计 ÷ 资产总额 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 非流动负债合计 | balance_sheet | totalNonCurrentLiabilities |
| 资产总额 | balance_sheet | totalAssets |

#### 业务含义
反映长期负债在总资产中的比重，衡量长期财务压力。

---

### 2.6 权益乘数 (Equity Multiplier)

**指标编码**: `EQUITY_MULTIPLIER`
**单位**: 倍
**权重**: 0.02
**最优范围**: 1.5 - 3.0

#### 计算公式
```
权益乘数 = 资产总额 ÷ 所有者权益总额
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 资产总额 | balance_sheet | totalAssets |
| 所有者权益总额 | balance_sheet | totalEquity |

#### 业务含义
反映企业的财务杠杆程度。权益乘数越大，股东投入资本带来的资产越多，但同时风险也越大。

---

## 三、盈利能力指标（7个）

### 3.1 销售毛利率 (Gross Profit Margin)

**指标编码**: `GROSS_PROFIT_MARGIN`
**单位**: %
**权重**: 0.04
**最优范围**: > 20%（因行业而异）

#### 计算公式
```
销售毛利率 = [(营业收入 - 营业成本) ÷ 营业收入] × 100%
           = (毛利 ÷ 营业收入) × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 营业收入 | income_statement | totalOperatingIncome 或 OPERATING_REVENUE |
| 营业成本 | income_statement | totalOperatingCost 或 OPERATING_COST |

#### 业务含义
反映产品或服务的初始盈利能力。毛利率高说明产品竞争力强或成本控制好。

#### 判断标准（制造业参考）
- **> 30%**: 优秀
- **20% - 30%**: 良好
- **10% - 20%**: 一般
- **< 10%**: 较低，需关注

---

### 3.2 营业利润率 (Operating Profit Margin)

**指标编码**: `OPERATING_PROFIT_MARGIN`
**单位**: %
**权重**: 0.04
**最优范围**: > 10%

#### 计算公式
```
营业利润率 = 营业利润 ÷ 营业收入 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 营业利润 | income_statement | operatingProfit |
| 营业收入 | income_statement | totalOperatingIncome |

#### 业务含义
反映企业经营业务的盈利能力，剔除了非经常性损益的影响。

---

### 3.3 销售净利率 (Net Profit Margin)

**指标编码**: `NET_PROFIT_MARGIN`
**单位**: %
**权重**: 0.05
**最优范围**: > 5%

#### 计算公式
```
销售净利率 = 净利润 ÷ 营业收入 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 净利润 | income_statement | netProfit |
| 营业收入 | income_statement | totalOperatingIncome |

#### 业务含义
反映企业最终盈利能力，是综合盈利能力的体现。

---

### 3.4 总资产收益率 ROA (Return on Assets)

**指标编码**: `ROA`
**单位**: %
**权重**: 0.04
**最优范围**: > 5%

#### 计算公式
```
ROA = 净利润 ÷ 平均资产总额 × 100%

平均资产总额 = (期初资产总额 + 期末资产总额) ÷ 2
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 净利润 | income_statement | netProfit |
| 期末资产总额 | balance_sheet（本期） | totalAssets |
| 期初资产总额 | balance_sheet（上期） | totalAssets |

**特殊处理**: 如果没有上期数据，使用本期资产总额代替平均值。

#### 业务含义
反映企业全部资产的盈利能力。ROA越高，资产利用效率越好。

---

### 3.5 净资产收益率 ROE (Return on Equity)

**指标编码**: `ROE`
**单位**: %
**权重**: 0.05
**最优范围**: > 10%（高于无风险利率）

#### 计算公式
```
ROE = 净利润 ÷ 平均所有者权益 × 100%

平均所有者权益 = (期初所有者权益 + 期末所有者权益) ÷ 2
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 净利润 | income_statement | netProfit |
| 期末所有者权益 | balance_sheet（本期） | totalEquity |
| 期初所有者权益 | balance_sheet（上期） | totalEquity |

#### 业务含义
反映股东权益的收益水平。ROE是投资者最关注的指标之一，体现资本回报能力。

#### 杜邦分析分解
```
ROE = 销售净利率 × 资产周转率 × 权益乘数
    = (净利润/营收) × (营收/总资产) × (总资产/权益)
```

---

### 3.6 每股收益 EPS (Earnings Per Share)

**指标编码**: `EPS`
**单位**: 元/股
**权重**: 0.02
**最优范围**: > 0 且持续增长

#### 计算公式
```
EPS = 归属于母公司股东的净利润 ÷ 发行在外普通股加权平均股数
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 归母净利润 | income_statement | netProfitDeducted |
| 总股本 | balance_sheet_item | PAID_IN_CAPITAL（需转换为股数） |

**注意**: 对于非上市公司，此指标仅供参考或跳过计算。

#### 业务含义
反映每股创造的利润，是股价的重要基础。

---

### 3.7 成本费用利润率 (Cost-Expense Profit Ratio)

**指标编码**: `COST_EXPENSE_PROFIT_RATIO`
**单位**: %
**权重**: 0.01
**最优范围**: > 15%

#### 计算公式
```
成本费用利润率 = 利润总额 ÷ 成本费用总额 × 100%

成本费用总额 = 营业成本 + 税金及附加 + 销售费用 + 管理费用 + 研发费用 + 财务费用
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 利润总额 | income_statement | totalProfit |
| 各项费用 | income_statement_item | 对应项目编码 |

#### 业务含义
反映企业耗费一定成本费用后能创造多少利润。该指标越高，成本费用控制得越好。

---

## 四、营运效率指标（7个）

### 4.1 应收账款周转率 (Accounts Receivable Turnover)

**指标编码**: `AR_TURNOVER`
**单位**: 次
**权重**: 0.03
**最优范围**: 6 - 12 次/年

#### 计算公式
```
应收账款周转率 = 营业收入 ÷ 平均应收账款余额

平均应收账款 = (期初应收账款 + 期末应收账款) ÷ 2
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 营业收入 | income_statement | totalOperatingIncome |
| 应收账款（期末） | balance_sheet_item | ACCOUNTS_RECEIVABLE |
| 应收账款（期初） | balance_sheet_item（上期） | ACCOUNTS_RECEIVABLE |

#### 业务含义
反映应收账款的周转速度。周转率高说明回款快，坏账风险低。

---

### 4.2 应收账款周转天数 (Days Sales Outstanding, DSO)

**指标编码**: `DSO`
**单位**: 天
**权重**: 0.03
**最优范围**: 30 - 60 天

#### 计算公式
```
应收账款周转天数 = 360 ÷ 应收账款周转率
                 = (平均应收账款 ÷ 营业收入) × 360
```

#### 输入字段来源: 同应收账款周转率

#### 业务含义
将应收账款周转率转化为更直观的天数形式。DSO越短，资金回笼越快。

#### 判断标准
- **< 30天**: 优秀
- **30 - 60天**: 正常
- **60 - 90天**: 偏慢，需关注
- **> 90天**: 很慢，坏账风险高

---

### 4.3 存货周转率 (Inventory Turnover)

**指标编码**: `INVENTORY_TURNOVER`
**单位**: 次
**权重**: 0.03
**最优范围**: 4 - 8 次/年（因行业而异）

#### 计算公式
```
存货周转率 = 营业成本 ÷ 平均存货余额

平均存货 = (期初存货 + 期末存货) ÷ 2
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 营业成本 | income_statement | totalOperatingCost |
| 存货（期末） | balance_sheet_item | INVENTORY |
| 存货（期初） | balance_sheet_item（上期） | INVENTORY |

#### 业务含义
反映存货的周转速度。周转率高说明存货管理效率高，占用资金少。

---

### 4.4 存货周转天数 (Days Inventory Outstanding, DIO)

**指标编码**: `DIO`
**单位**: 天
**权重**: 0.03
**最优范围**: 45 - 90 天

#### 计算公式
```
存货周转天数 = 360 ÷ 存货周转率
             = (平均存货 ÷ 营业成本) × 360
```

#### 输入字段来源: 同存货周转率

#### 业务含义
存货从入库到销售出去的平均天数。DIO越短，存货变现越快。

---

### 4.5 总资产周转率 (Total Asset Turnover)

**指标编码**: `ASSET_TURNOVER`
**单位**: 次
**权重**: 0.04
**最优范围**: 0.5 - 1.5 次/年

#### 计算公式
```
总资产周转率 = 营业收入 ÷ 平均资产总额
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 营业收入 | income_statement | totalOperatingIncome |
| 平均资产总额 | balance_sheet（本期+上期） | totalAssets |

#### 业务含义
反映企业全部资产的利用效率。周转率越高，资产运营效率越好。

---

### 4.6 固定资产周转率 (Fixed Asset Turnover)

**指标编码**: `FIXED_ASSET_TURNOVER`
**单位**: 次
**权重**: 0.02
**最优范围**: 2 - 5 次/年

#### 计算公式
```
固定资产周转率 = 营业收入 ÷ 平均固定资产净值

固定资产净值 = 固定资产原值 - 累计折旧
             ≈ balance_sheet中的FIXED_ASSETS
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 营业收入 | income_statement | totalOperatingIncome |
| 固定资产 | balance_sheet_item | FIXED_ASSETS |

#### 业务含义
反映固定资产的利用效率。特别适用于制造型企业。

---

### 4.7 营业周期 (Operating Cycle)

**指标编码**: `OPERATING_CYCLE`
**单位**: 天
**权重**: 0.02
**最优范围**: < 120 天

#### 计算公式
```
营业周期 = 应收账款周转天数 + 存货周转天数
         = DSO + DIO
```

#### 输入字段来源: 由上述两个指标计算得出

#### 业务含义
从购入存货到收回销售款项所需的完整周期。营业周期越短，资金周转越快。

---

## 五、现金流能力指标（6个）

### 5.1 现金流量比率 (Cash Flow Ratio)

**指标编码**: `CASH_FLOW_RATIO`
**单位**: %
**权重**: 0.04
**最优范围**: > 100%

#### 计算公式
```
现金流量比率 = 经营活动现金流量净额 ÷ 流动负债 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 经营活动现金流净额 | cash_flow_statement | netCashFlowOperating |
| 流动负债合计 | balance_sheet | totalCurrentLiabilities |

#### 业务含义
反映经营活动产生的现金能否覆盖流动负债。这是比流动比率更真实的偿债能力指标。

#### 判断标准
- **> 100%**: 经营现金流足以偿还短期债务
- **50% - 100%**: 需要其他资金补充
- **< 50%**: 现金流严重不足

---

### 5.2 经营现金净流量与净利润比率 (Operating Cash Flow to Net Income)

**指标编码**: `OCF_TO_NI_RATIO`
**单位**: %
**权重**: 0.03
**最优范围**: 80% - 120%

#### 计算公式
```
经营现金净流量与净利润比率 = 经营活动现金流量净额 ÷ 净利润 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 经营活动现金流净额 | cash_flow_statement | netCashFlowOperating |
| 净利润 | income_statement | netProfit |

#### 业务含义
反映利润的质量。如果该比率持续低于100%，说明盈利主要来自应收账款或应计项目，实际现金流较差。

#### 判断标准
- **> 100%**: 利润质量高，现金流充裕
- **80% - 100%**: 正常
- **50% - 80%**: 利润质量一般
- **< 50%**: 利润质量差，警惕虚增利润

---

### 5.3 现金再投资比率 (Cash Reinvestment Ratio)

**指标编码**: `CASH_REINVESTMENT_RATIO`
**单位**: %
**权重**: 0.02
**最优范围**: 8% - 12%

#### 计算公式
```
现金再投资比率 = (经营活动现金流量净额 - 现金股利) ÷ (固定资产购置 + 其他投资) × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 经营活动现金流净额 | cash_flow_statement | netCashFlowOperating |
| 资本性支出 | cash_flow_statement_item | CASH_PAID_FOR_ACQUISITION_OF_LONG_TERM_ASSETS |

**简化版**（如果无法获取股利数据）:
```
现金再投资比率 ≈ 经营活动现金流量净额 ÷ 总资产 × 100%
```

#### 业务含义
反映企业将经营现金流用于再投资的能力。

---

### 5.4 现金到期债务比 (Cash to Current Maturity Debt Ratio)

**指标编码**: `CASH_TO_MATURITY_DEBT_RATIO`
**单位**: %
**权重**: 0.02
**最优范围**: > 100%

#### 计算公式
```
现金到期债务比 = 经营活动现金流量净额 ÷ 本期到期债务 × 100%

本期到期债务 ≈ 一年内到期的非流动负债 + 短期借款（可选）
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 经营活动现金流净额 | cash_flow_statement | netCashFlowOperating |
| 一年内到期非流动负债 | balance_sheet_item | NON_CURRENT_LIABILITIES_DUE_WITHIN_ONE_YEAR |

#### 业务含义
衡量本期到期的债务有多少可以用经营现金流来偿还。

---

### 5.5 销售收现率 (Sales Cash Collection Rate)

**指标编码**: `SALES_CASH_COLLECTION_RATE`
**单位**: %
**权重**: 0.02
**最优范围**: 90% - 110%

#### 计算公式
```
销售收现率 = 销售商品收到现金 ÷ 营业收入 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名/编码 |
|-----|-------|------------|
| 销售商品收到现金 | cash_flow_statement_item | CASH_RECEIVED_FROM_SALES |
| 营业收入 | income_statement | totalOperatingIncome |

#### 业务含义
反映销售收入的现金回收情况。接近100%说明销售基本都收到了现金；远超100%可能意味着回收了前期欠款。

---

### 5.6 现金满足内部需要比率 (Internal Cash Sufficiency Ratio)

**指标编码**: `INTERNAL_CASH_SUFFICIENCY_RATIO`
**单位**: %
**权重**: 0.02
**最优范围**: > 100%

#### 计算公式
```
现金满足内部需要比率 = 近5年经营活动现金流量净额之和 ÷ (近5年资本支出 + 近5年存货增加 + 近5年现金股利) × 100%
```

**简化版**（单期）:
```
≈ 经营活动现金流量净额 ÷ (资本性支出 + 存货增加额) × 100%
```

#### 业务含义
反映企业内生增长的资金自给能力。

---

## 六、成长能力指标（5个）

### 6.1 营业收入增长率 (Revenue Growth Rate)

**指标编码**: `REVENUE_GROWTH_RATE`
**单位**: %
**权重**: 0.04
**最优范围**: > 10%（可持续增长）

#### 计算公式
```
营业收入增长率 = (本期营业收入 - 上期营业收入) ÷ 上期营业收入 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 本期营业收入 | income_statement（本期） | totalOperatingIncome |
| 上期营业收入 | income_statement（上期） | totalOperatingIncome |

#### 业务含义
反映企业营业收入的扩张速度。稳定的正增长率是企业健康成长的基础。

#### 判断标准
- **> 20%**: 高速增长
- **10% - 20%**: 稳健增长
| **0% - 10%**: 缓慢增长
- **< 0%**: 营收下滑，需警惕

---

### 6.2 净利润增长率 (Net Profit Growth Rate)

**指标编码**: `NET_PROFIT_GROWTH_RATE`
**单位**: %
**权重**: 0.04
**最优范围**: > 营收增长率

#### 计算公式
```
净利润增长率 = (本期净利润 - 上期净利润) ÷ 上期净利润 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 本期净利润 | income_statement（本期） | netProfit |
| 上期净利润 | income_statement（上期） | netProfit |

#### 业务含义
反映企业盈利的增长速度。理想情况下，净利润增速应超过营收增速（规模效应）。

---

### 6.3 总资产增长率 (Total Asset Growth Rate)

**指标编码**: `ASSET_GROWTH_RATE`
**单位**: %
**权重**: 0.02
**最优范围**: 5% - 20%

#### 计算公式
```
总资产增长率 = (期末总资产 - 期初总资产) ÷ 期初总资产 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 期末总资产 | balance_sheet（本期） | totalAssets |
| 期初总资产 | balance_sheet（上期） | totalAssets |

#### 业务含义
反映企业资产规模的扩张速度。过快可能带来管理压力，过慢可能错失发展机会。

---

### 6.4 所有者权益增长率 (Equity Growth Rate)

**指标编码**: `EQUITY_GROWTH_RATE`
**单位**: %
**权重**: 0.03
**最优范围**: > 5%

#### 计算公式
```
所有者权益增长率 = (期末所有者权益 - 期初所有者权益) ÷ 期初所有者权益 × 100%
```

#### 输入字段来源
| 参数 | 来源表 | 字段名 |
|-----|-------|--------|
| 期末所有者权益 | balance_sheet（本期） | totalEquity |
| 期初所有者权益 | balance_sheet（上期） | totalEquity |

#### 业务含义
反映股东财富的增长速度。持续的正增长说明企业在为股东创造价值。

---

### 6.5 资本积累率 (Capital Accumulation Rate)

**指标编码**: `CAPITAL_ACCUMULATION_RATE`
**单位**: %
**权重**: 0.02
**最优范围**: > 7%（高于GDP增速+CPI）

#### 计算公式
```
资本积累率 = (本期所有者权益 - 上期所有者权益) ÷ 上期所有者权益 × 100%
```

**注**: 与所有者权益增长率计算方法相同，但强调留存收益的积累。

#### 业务含义
反映企业资本保全和增值的能力。该指标越高，企业发展后劲越足。

## 同比环比计算方法

### 同比 (Year-over-Year, YoY)

**定义**: 与去年同期相比的变化率

**适用场景**: 年报数据、季度数据（与上年同期比）

**计算公式**:
```
同比增长率 = (本期值 - 上年同期值) ÷上年同期值 × 100%
```

**示例**:
```
2024Q3 营业收入 = 30,000 万元
2023Q3 营业收入 = 28,000 万元
YoY = (30,000 - 28,000) ÷ 28,000 × 100% = 7.14%
```

### 环比 (Quarter-over-Quarter, QoQ)

**定义**: 与上一期相比的变化率

**适用场景**: 连续的季度/月度数据

**计算公式**:
```
环比增长率 = (本期值 - 上期值) ÷ 上期值 × 100%
```

**示例**:
```
2024Q3 营业收入 = 30,000 万元
2024Q2 营业收入 = 29,000 万元
QoQ = (30,000 - 29,000) ÷ 29,000 × 100% = 3.45%
```

### 季节性调整（可选）

对于受季节性影响较大的行业（如零售、农业），可进行季节性调整：

```
季节调整后值 = 原始值 ÷ 季节因子
季节因子 = 当期历史平均值 ÷ 全年平均值
```

## 异常值处理逻辑

### 1. 缺失数据处理

| 场景 | 处理方式 | 示例 |
|------|---------|------|
| 本期有数据，上期缺失 | 无法计算增长率，返回null | 新成立企业首年报 |
| 分母为零或极小 | 返回null，标记为"无法计算" | 盈利为负时计算ROE |
| 关键字段全部缺失 | 整个指标返回null，is_calculable=false | 报表不完整 |
| 部分明细缺失 | 尽量用汇总数据替代 | 缺少存货明细时用流动资产估算 |

### 2. 异常值检测

**阈值警告机制**:

```java
// 伪代码：异常值检测
function detectAnomaly(value, indicatorCode) {
    let range = getNormalRange(indicatorCode);  // 获取正常范围
    if (value < range.min || value > range.max) {
        return {
            isAbnormal: true,
            severity: calculateSeverity(value, range),  // WARNING/DANGER
            message: `${value} 超出正常范围 ${range.min}-${range.max}`
        };
    }
    return { isAbnormal: false };
}
```

**典型异常阈值**:

| 指标 | 下限警告 | 下限危险 | 上限警告 | 上限危险 |
|------|---------|---------|---------|---------|
| 流动比率 | < 1.0 | < 0.5 | > 4.0 | > 6.0 |
| 资产负债率 | > 70% | > 90% | - | - |
| ROE | < 0% | < -10% | > 30% | > 50% |
| 应收账款周转天数 | > 90天 | > 180天 | - | - |
| 营业收入增长率 | < -20% | < -50% | > 100% | > 200% |

### 3. 数据一致性校验

**勾稽关系检查**:

1. **资产负债表平衡**:
   ```
   |总资产 - (总负债 + 所有者权益)| < tolerance (0.01万元)
   ```

2. **利润表勾稽**:
   ```
   营业收入 - 营业成本 - 税金 - 三费 ± 其他 ≈ 净利润 (误差<0.01%)
   ```

3. **现金流量表勾稽**:
   ```
   期初现金 + 净增加额 ≈ 期末现金 (误差<0.01万元)
   ```

4. **跨表一致性**:
   ```
   利润表净利润 ≈ 现金流量表附注中的净利润
   资产负债表货币资金 ≈ 现金流量表期末余额
   ```

## 指标计算服务实现说明

### 服务类位置
- **接口**: `com.xinsulu.service.FinancialReportService`
- **实现**: `com.xinsulu.service.impl.FinancialReportServiceImpl`

### 核心方法

```java
/**
 * 计算指定报表的所有财务指标
 * @param archiveId 报表档案ID
 * @return Map<指标编码, 指标值>
 */
public Map<String, BigDecimal> calculateAllIndicators(Long archiveId);

/**
 * 计算单个指标
 */
public BigDecimal calculateIndicator(String indicatorCode, Long archiveId);

/**
 * 计算五维健康评分
 */
public HealthScoreVO calculateHealthScore(Long archiveId);

/**
 * 计算同比环比
 */
public TrendData calculateTrend(Long enterpriseId, String indicatorCode, int periods);
```

### 计算流程

```
1. 加载报表数据
   ├── 获取资产负债表（本期+上期）
   ├── 获取利润表（本期+上期）
   └── 获取现金流量表（本期）

2. 数据预处理
   ├── 单位统一（确保都是万元）
   ├── 空值处理（标记缺失字段）
   └── 异常值检测

3. 按类别计算指标
   ├── 短期偿债能力（5个）
   ├── 长期偿债能力（6个）
   ├── 盈利能力（7个）
   ├── 营运效率（7个）
   ├── 现金流能力（6个）
   └── 成长能力（5个）

4. 后处理
   ├── 精度调整（四舍五入到指定位数）
   ├── 风险状态判定（SAFE/WARNING/DANGER/CRITICAL）
   ├── 趋势方向判断（UP/DOWN/STABLE）
   └── 评分贡献分计算

5. 结果存储
   ├── 写入 financial_indicator_value 表
   ├── 更新 historical_indicator_value 表
   └── 计算 health_score 并写入
```

## 性能优化建议

### 1. 批量计算
- 对同一企业的多个期间批量计算，减少数据库往返
- 使用JPA的@BatchSize注解优化关联查询

### 2. 缓存策略
- 指标定义（financial_indicator）缓存到Redis，几乎不变
- 计算结果缓存24小时，除非数据更新

### 3. 异步计算
- 报表审核通过后触发异步计算任务
- 使用消息队列解耦

### 4. 增量计算
- 新增报表时只计算当期指标
- 历史趋势指标异步更新
